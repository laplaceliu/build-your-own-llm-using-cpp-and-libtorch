= 第 3 章 编码注意力机制

本章用 C++ + LibTorch 从零实现 4 种注意力机制变体，对应代码位于
`chapters/chapter03_attention/`。中间每一步的结果都会打印，且与书中 Python 输出
**逐值一致**（含 `torch::manual_seed` 生成的权重、`nn.Linear` 的 kaiming 初始化、
dropout 的随机掩码模式——CPU 上 C++ 与 Python 共享同一 RNG）。

* `include/attention.h` —— 5 个注意力类（代码清单 3-1 ~ 3-5 的 C++ 版）
* `src/main.cpp` —— 按 3.3~3.6 逐步演示

== 3.3 简单自注意力（无可训练权重）

输入为 6 个 3 维词元嵌入（"Your journey starts with one step."），与书一致。

3.3.1 以第 2 个词元为 query，用点积计算注意力分数并归一化：

[source,text]
----
attn_scores_2     = [0.9544, 1.4950, 1.4754, 0.8434, 0.7070, 1.0865]
attn_weights_2    = [0.1385, 0.2379, 0.2333, 0.1240, 0.1082, 0.1581]   # softmax
context_vec_2     = [0.4419, 0.6515, 0.5683]
----

3.3.2 推广到全部 6 个查询：

* 双循环点积 与 `inputs @ inputs.T` 得到相同的 6×6 分数矩阵
* `attn_weights = softmax(scores, dim=-1)`，每行之和为 1
* `all_context_vecs = attn_weights @ inputs`（6×3），第 2 行与 3.3.1 的 `context_vec_2` 一致

== 3.4 带可训练权重的自注意力

=== 3.4.1 逐步计算

`d_in=3, d_out=2`，`torch::manual_seed(123)` 后 `torch::rand` 生成 `W_query/W_key/W_value`：

[source,text]
----
query_2        = [0.4306, 1.4551]
attn_score_22  = 1.8524
attn_scores_2  = [1.2705, 1.8524, 1.8111, 1.0795, 0.5577, 1.5440]
attn_weights_2 = [0.1500, 0.2264, 0.2199, 0.1311, 0.0906, 0.1820]   # softmax(scores/√d_k)
context_vec_2  = [0.3061, 0.8210]
----

=== 3.4.2 SelfAttention_v1 / v2

`SelfAttentionV1` 用 `torch::rand` 初始化参数；`SelfAttentionV2` 用 `nn::Linear`
（kaiming 初始化，权重转置存储）。两版输出均与书一致：

[source,text]
----
sa_v1(inputs)（seed 123）第 2 行 = [0.3061, 0.8210]
sa_v2(inputs)（seed 789）第 1 行 = [-0.0739, 0.0713]
----

*练习 3.1*：把 `sa_v2` 的 `nn::Linear` 权重转置后赋给 `sa_v1`（`W = linear.weight.t()`），
两版输出逐值一致——已在程序内验证。

== 3.5 因果注意力

=== 3.5.1 掩码实现

两种等价方法均输出与书一致的 6×6 矩阵：

* 方法一：`attn_weights * tril(mask)` 再按行归一化（`masked_simple_norm`）
* 方法二（更高效）：`masked_fill(triu(diagonal=1), -inf)` 后 `softmax`，结果相同

例如归一化后第 2 行 = `[0.5517, 0.4483, 0, ...]`。

=== 3.5.2 dropout

`torch::manual_seed(123)` + `nn::Dropout(0.5)`，与书一样得到约一半被置 0、其余放大 2 倍的
矩阵（含全 1 示例与真实注意力权重的 dropout 结果）。

=== 3.5.3 CausalAttention 类

支持 batch：`batch = stack((inputs, inputs))` 形状 `[2, 6, 3]`。掩码用 `register_buffer`
存储（随模型移动设备）。输出形状 `[2, 6, 2]`，数值与书一致（第 1 行 `[-0.4519, 0.2216]`）。

== 3.6 多头注意力

=== 3.6.1 MultiHeadAttentionWrapper（堆叠单头）

`num_heads=2`、`d_out=2` → 沿最后一维拼接 → `[2, 6, 4]`，数值与书一致。

*练习 3.2*：`d_out=1, num_heads=2` → 输出 `[2, 6, 2]`（已在程序内演示）。

=== 3.6.2 MultiHeadAttention（权重划分 + 批矩阵乘）

* `view(b, n, num_heads, head_dim)` + `transpose(1,2)` 拆分多头
* 4 维批矩阵乘 `a @ a.transpose(2,3)` 与逐头 `head @ head.T` 结果一致（书中的 `(1,2,3,4)` 例子）
* `out_proj` 输出投影层；输出 `[2, 6, 2]`，数值与书一致（第 1 行 `[0.3190, 0.4858]`）

*练习 3.3*：GPT-2 规模 `MultiHeadAttention(768, 768, context=1024, heads=12)`，
输入 `[2, 8, 768]` → 输出 `[2, 8, 768]`（已在程序内验证）。

== 移植说明（libtorch 2.13 C++ API 差异）

* 参数即 `torch::Tensor`，经 `register_parameter("W_query", torch::rand({...}))` 注册（无 `nn::Parameter` 类型）
* 子模块成员声明用 `torch::nn::Linear W_query\{nullptr\}`（避免默认构造断言）
* buffer 用 `register_buffer` 返回的 `Tensor&` 存成员变量
* 多头 wrapper 用 `std::vector<std::shared_ptr<CausalAttentionImpl>>` 存各头

== GPU 加速

程序自动检测 CUDA 并把输入张量（`make_inputs().to(device)`）与各注意力模块
（`.to(device)`）迁移到 GPU（设备打印 `cuda:0`）。权重仍在 CPU 上 `manual_seed`
初始化后再迁移，因此所有数值（`attn_scores_2`、`context_vec_2`、`sa_v1(inputs)`、
因果掩码、MHA 输出等）**与书逐值一致**。程序开头禁用 TF32
（`setAllowTF32CuBLAS(false)`）保证 GPU matmul 精度与 CPU 一致。
