= 第 1 章 Hello LibTorch：张量基础

本章目标：

* 验证 LibTorch 环境可编译、可运行
* 认识 `torch::Tensor`：创建张量、查看形状 / 数据类型 / 设备
* 完成第一次矩阵乘法

对应代码：`chapters/chapter01_hello_torch/main.cpp`

== 1.1 代码讲解

`torch/torch.h` 是 LibTorch C++ API 的主头文件；`torch/cuda.h` 提供 CUDA 可用性查询。

[source,cpp]
----
#include <torch/cuda.h>
#include <torch/torch.h>

#include <iostream>

int main() {
  // 创建两个张量：x 为 2x3，w 为 3x1
  auto x = torch::tensor({{1.0f, 2.0f, 3.0f}, {4.0f, 5.0f, 6.0f}});
  auto w = torch::tensor({{1.0f}, {1.0f}, {1.0f}});

  // 矩阵乘法 x @ w -> (2,1)
  auto y = x.matmul(w);

  // 张量元信息：形状 / 数据类型 / 设备
  std::cout << "shape = " << x.sizes() << ", dtype = " << x.dtype()
            << ", device = " << x.device() << "\n";

  std::cout << "CUDA available: "
            << (torch::cuda::is_available() ? "yes" : "no") << "\n";
  return 0;
}
----

要点：

* `torch::tensor(...)` 从初始化列表创建张量，自动推断形状与数据类型。
* `tensor.sizes()` 返回 `IntArrayRef`，打印为 `[2, 3]`。
* `tensor.device()` 显示张量所在设备（`cpu` / `cuda:0`）。
* `torch::cuda::is_available()` 检查 CUDA 是否可用——在 GPU 版 LibTorch 下通常返回 `yes`。
