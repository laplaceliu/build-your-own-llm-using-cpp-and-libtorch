## 正文大纲

### 1. 背景：为什么会有这个系列（30 秒）
- 市面上的 LLM 教程几乎都是 Python 版
- 但生产部署环境（C++ 后端、嵌入式、车载）需要 C++ 视角
- Sebastian Raschka 的《Build a Large Language Model (From Scratch)》是公认最好的入门书，但只有 Python
- 这个系列 = **用 C++ + LibTorch 一比一复刻**那本书

### 2. 这 10 周要做什么（30 秒）
- **7 章主课**：Hello LibTorch → 文本数据 → 注意力 → GPT 模型 → 预训练 → 分类微调 → 指令微调
- **3 章附录**：训练循环技巧、LoRA、推理增强
- **3 个实战项目**：
  - `gpt-bash`：自然语言 → Bash 命令
  - `gpt-toolcall`：让模型学会调用工具
  - `gpt-sft`：通用 SFT 框架（CLI + HTTP 服务）
- 总计 **43 帖**，每周 3–4 帖更

### 3. 你能从这个系列里得到什么（30 秒）
- ✅ **跨语言数值一致**：同一份随机种子，C++ 与 PyTorch 输出完全一致
- ✅ **性能调优的真实数据**：CPU vs GPU 实测对比（5 分钟训练 vs 8 秒）
- ✅ **可部署形态**：单二进制文件 + 模型权重，不依赖 Python 运行时
- ✅ **3 个完整项目**：跑得起来的代码，不是片段

### 4. 难度自评与前置条件（30 秒）
- **必须**：C++11 基础（懂类、模板、智能指针）、线性代数（矩阵乘法、softmax）
- **加分**：用过 PyTorch、读过《动手学深度学习》或 Raschka 原书
- **不需要**：CUDA 编程（LibTorch 帮你屏蔽了）

### 5. 预期产出（30 秒）
- **小目标**：跟着做能跑通 GPT-2 small（124M 参数）全流程
- **中目标**：在指令微调数据集上微调出可用模型
- **大目标**：理解「模型 → 训练 → 部署」全链路，为下一步学 Llama 架构打基础
