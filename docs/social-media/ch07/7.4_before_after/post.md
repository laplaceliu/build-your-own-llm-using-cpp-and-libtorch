## 对比 1：知识问答

**prompt**：解释什么是量子纠缠

**Base（未微调）**：
> 量子纠缠是指两个量子系统之间的相互关系。量子纠缠是指两个量子系统之间的相互关系。量子纠缠是指两个量子系统之间的相互关系。量子纠缠是指两个量子系统之间的相互关系...

😱 **重复循环**，典型的 base model 毛病。

**SFT（微调后）**：
> 量子纠缠是量子力学中的一种特殊现象，指两个或多个粒子在相互作用后，即使相隔很远，它们的量子状态也会瞬间相互影响。这种关联无法用经典物理解释，是量子计算和量子通信的基础。

✅ 结构清晰、内容准确。

## 对比 2：代码生成

**prompt**：用 Python 写一个快速排序

**Base**：
> def quick_sort(arr):
>     if len(arr) > 1:
>         pivot = arr[0]
>         less = [x for x in arr[1:] if x <= pivot]
>         greater = [x for x in arr[1:] if x > pivot]
>         return quick_sort(less) + [pivot] + quick_sort(greater)
>     return arr

✅ 居然能写对（训练集里见过），但没有注释。

**SFT**：
> def quick_sort(arr):
>     """快速排序：递归 + 分治"""
>     if len(arr) <= 1:
>         return arr
>     pivot = arr[len(arr) // 2]
>     left = [x for x in arr if x < pivot]
>     middle = [x for x in arr if x == pivot]
>     right = [x for x in arr if x > pivot]
>     return quick_sort(left) + middle + quick_sort(right)
>
> # 测试
> print(quick_sort([3, 6, 1, 8, 2]))  # [1, 2, 3, 6, 8]

✅ 有 docstring、有测试，更专业。

## 对比 3：文案改写

**prompt**：把这句话改写得更礼貌：「把报告发给我」

**Base**：
> 把报告发给我。把报告发给我。把报告发给我...

😱 **复读**。

**SFT**：
> 您好，方便的时候能否把报告发送给我？感谢您！

✅ 礼貌得体。

## 对比 4：摘要

**prompt**：总结这段话："人工智能正在改变各行各业。从医疗诊断到自动驾驶，从教育到金融，AI 应用无处不在。然而，AI 的发展也带来了隐私、就业、伦理等问题。"

**Base**：
> 人工智能正在改变各行各业...人工智能正在改变各行各业...（继续重复原文）

😱 **复读**。

**SFT**：
> AI 正在医疗、教育、金融等多个领域广泛应用，但同时也引发了隐私、就业和伦理方面的挑战。

✅ 50 字讲清楚全文。

## 对比 5：多步推理

**prompt**：小明有 5 个苹果，吃了 2 个，又买了 3 个，现在有几个？

**Base**：
> 5 - 2 + 3 = 6. Now let me think about... 5 - 2 + 3 = 6. Now let me think...

😱 **算对了但反复重复**。

**SFT**：
> 让我一步步算：
> 1. 小明有 5 个苹果
> 2. 吃了 2 个 → 5 - 2 = 3 个
> 3. 又买了 3 个 → 3 + 3 = 6 个
>
> 答：小明现在有 6 个苹果。

✅ 步骤清晰。

| 类型 | Base | SFT | 提升 |
|---|---|---|---|
| 知识问答 | 重复循环 | 结构清晰 | ★★★★★ |
| 代码生成 | 正确无注释 | 带文档 | ★★★ |
| 文案改写 | 复读 | 得体礼貌 | ★★★★★ |
| 摘要 | 复读 | 简洁准确 | ★★★★★ |

**最大提升**：问答 / 改写 / 摘要类任务

## 失败案例

**prompt**：写一首关于春天的七言绝句

**SFT**：
> 春风拂面万物醒，碧水青山映日新。
> 鸟语花香满园中，诗情画意醉人心。

❌ 七言绝句只有四句，但每句字数不对，且「醉人心」不算七言（醉人 2 字）。
**原因**：模型没见过古诗训练数据。
