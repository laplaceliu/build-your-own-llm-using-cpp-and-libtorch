## 单帖目录模板

每个帖目录下放 4 个文件：

```
{post_id}/
├── README.md       ← 状态 / checklist / 发布后跟踪
├── outline.md      ← 大纲：钩子、要点、视觉清单、素材索引
├── script.md       ← 口播脚本（按秒分段）
└── post.md         ← 正文（小红书 / 知乎）
```

## 生产流程

每帖的标准化生产流程：

1. **写 `outline.md`** — 从 `social-media-plan.md` 拷贝骨架，按帖细化
2. **写 `script.md`** — 口播脚本，按秒分段
3. **写 `post.md`** — 完整正文，含代码示例
4. **制图 `assets/`** — 按 outline 的视觉清单逐张制作
5. **填 `README.md`** — 状态推进到 🟡
6. **校对** — 数据、术语、代码三遍过
7. **发布** — 状态推进到 ✅，填跟踪表

---

## 协作约定

- 每个帖子独立目录，**互不依赖**
- 共享素材放 `assets/`，单帖专属放帖目录下
- 命名一律英文小写 + 下划线，便于跨平台
- `script.md` 用 `【配图】` 标注图片切换点，便于剪辑
