= 第 5 章 在无标签数据上进行预训练

本章用 C++ + LibTorch 实现 GPT 模型的评估、预训练、解码策略与权重加载，
对应代码位于 `chapters/chapter05_pretraining/`。

* `include/training.h` —— 损失/评估/训练循环/generate 解码函数
* `include/dataloader.h` —— 第 2 章滑动窗口数据加载器（复用）
* `include/safetensors.h` + `src/safetensors.cpp` —— safetensors 权重解析器
* `src/main.cpp` —— 5.1~5.5 逐步演示

== 5.5 从 OpenAI 加载预训练权重

书中用 TensorFlow 解析 OpenAI 的 checkpoint；本实现改为 C++ 直接解析 HuggingFace
`safetensors`（`gpt2` 模型，权重与 OpenAI 相同，`~548 MB`），键名映射到书中
`params` 结构后，加载逻辑与代码清单 5-5 完全一致：

* 下载：`curl -fsSL -L -o data/gpt2-model.hf.safetensors https://hf-mirror.com/gpt2/resolve/main/model.safetensors`
  （或 huggingface.co；`attn.bias` 掩码 buffer 跳过）
* 加载：`gpt2-model.hf.safetensors` 传给第 3 个命令行参数
* 配置：`context_length=1024, qkv_bias=True`（与 OpenAI 一致）
* `c_attn.w [768,2304]` 按最后一维 split 成 q/k/v（书 `np.split(axis=-1)`）再转置

生成文本（top_k=50, temperature=1.5, seed 123）与书**逐字一致**：

== GPU 加速

程序自动检测 CUDA（设备打印 `cuda:0`），模型在 CPU 上 `manual_seed(123)` 初始化后
迁移 GPU，数据加载器批次同步迁移。程序开头禁用 TF32
（`setAllowTF32CuBLAS(false)`），保证 GPU matmul 与 CPU 精度一致。

* **确定性数值与书一致**：5.1.2 损失 10.7940 / 困惑度 48725.82、
  5.1.3 训练/验证损失 10.9876/10.9811，均与书逐值一致
* **训练加速**：10 轮预训练 CPU 约 8 分钟 → GPU（RTX 4080）约 10-15 秒（**~30 倍**）
* **生成文本**：贪心解码（5.1.1）与书一致；温度采样（5.3.3/5.5）因 multinomial
  随机性 + GPU 微小浮点差异，文本可能与书不同（同 CPU 版在 seed 123 下恰好复现书）

== 移植要点

* **in-place 赋值**：给 requires_grad 的叶子参数赋值须在 `NoGradGuard` 下
  `copy_`（等价 Python `with torch.no_grad()`）。
* **shuffle RNG**：C++ 与 Python 的 DataLoader shuffle 序列不同 → 训练损失
  曲线有微小差异（趋势一致）。
* **温度采样**：`generate` 用 `torch::multinomial`，随机性使生成文本不可逐字复现。
* **默认权重路径**：程序默认使用完整权重文件 `gpt2-model.hf.safetensors`（约 523 MB，
  见 5.5 下载命令）；不要用未下载完的残file，否则 safetensors 解析会越界崩溃。
