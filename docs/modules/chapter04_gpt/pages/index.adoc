= 第 4 章 从头实现 GPT 模型进行文本生成

本章用 C++ + LibTorch 组装出参数量 1.24 亿的 GPT-2 small 完整架构并实现文本生成，
对应代码位于 `chapters/chapter04_gpt/`。所有中间输出与书**逐值一致**
（含 logits、参数量、生成文本）。

* `include/gpt.h` —— LayerNorm / GELU / FeedForward / TransformerBlock / GPTModel /
  DummyGPTModel / ExampleDeepNeuralNetwork / generate_text_simple
* `src/main.cpp` —— 按 4.1~4.7 逐步演示 + 练习 4.1~4.3

依赖第 2 章 tokenizer 与第 3 章 `MultiHeadAttention`（CMake 中引用其源码/头文件）。

== 4.1 GPT 主干与输入批次

Output shape: [2, 4, 50257]

== 4.2 层归一化 LayerNorm

* 逐步演示：`Sequential(Linear(5,6), ReLU)`（seed 123）→ 打印 `mean/var` →
  `out_norm`（均值为 0、方差为 1）
* `LayerNorm` 类：`var(dim=-1, keepdim, unbiased=False)`（有偏方差，与 TensorFlow 版
  GPT-2 兼容），`scale`/`shift` 可训练参数

验证值：`out` 第 1 行 `[0.2260, 0.3470, 0, 0.2216, 0, 0]`、`mean = 0.1324`、
`var = 0.0231`，与书一致。

== 4.3 GELU 与 FeedForward

* GELU 用 tanh 近似（与原始 GPT-2 一致）：`0.5x(1+tanh(√(2/π)(x+0.044715x³)))`
* `FeedForward`: `Linear(768,3072) → GELU → Linear(3072,768)`，输入 `[2,3,768]` →
  输出 `[2,3,768]`（形状不变），参数量 4,722,432

== 4.4 快捷连接

`ExampleDeepNeuralNetwork`（5 层，`layer_sizes=[3,3,3,3,3,1]`）对比有无快捷连接的梯度
（MSE loss 对 target=0，seed 123）：

[source,text]
----
无快捷连接: 0.000202 / 0.000120 / 0.000715 / 0.001399 / 0.005050   # 梯度消失
有快捷连接: 0.221698 / 0.206941 / 0.328970 / 0.266573 / 1.325850   # 梯度稳定
----

与书完全一致。

== 4.5 TransformerBlock

Pre-LayerNorm + 快捷连接：`norm → att → drop → +shortcut → norm → ff → drop → +shortcut`。
输入 `[2,4,768]` → 输出 `[2,4,768]`（形状不变）。

完整 1.24 亿参数 GPT-2 small（seed 123）：

out[0][0][:3] = [0.3613, 0.4222, -0.0711]       # 与书逐值一致

Total size of the model: 621.832 MB
----

*练习 4.1*：FeedForward 4,722,432 vs MultiHeadAttention 2,360,064（前馈约为注意力的 2 倍）。

*练习 4.2*：同一 GPTModel 类 + 不同配置即可得到 medium/large/xl（程序内用公式估算，
避免实例化 6GB+ 的超大模型，并与 124M 的实际参数对比验证公式正确）：
medium 4.06 亿、large 8.38 亿、xl 16.38 亿（weight tying 后 3.55 / 7.74 / 15.57 亿）。

== 4.7 生成文本

`generate_text_simple` 贪心解码：截断上下文 → forward → softmax → argmax →
拼接新词元，循环 6 次（eval 模式关闭 dropout）：

[source,text]
----
encoded: [15496, 11, 314, 716]          # "Hello, I am"
Output: [15496, 11, 314, 716, 27018, 24086, 47843, 30961, 42348, 7267]
Output length: 10
Decoded text: "Hello, I am Featureiman Byeswickattribute argue"   # 未训练的无意义输出
----

与书完全一致。*练习 4.3*：模型中共 3 处 dropout（嵌入后、快捷连接、多头注意力内部）。

== 移植要点（C++ 特有坑）

* **函数参数求值顺序**：`Sequential(Linear, GELU(), Linear)` 单表达式构造会因
  C++ 未指定的参数求值顺序（GCC 从右到左）导致第二个 Linear 先初始化，
  RNG 与 Python 不同步，模型 logits 全错。必须逐个 `push_back`。
* **ModuleList 子模块命名**：`register_module` 的子模块名不能含 `.`，用
  `ModuleList`（自动编号）即可得到与 Python 一致的 `layers.0.0.weight` 键名。
* **`eval()` 模式**：生成前调用 `model->eval()` 关闭所有 dropout。
* **权重一致性**：C++ 与 Python 在 CPU 上共享 RNG，`manual_seed(123)` 后
  全部权重（Embedding/Linear/LayerNorm）逐值一致。

== GPU 加速

程序自动检测 CUDA，`GPTModel` 在 CPU 上 `manual_seed(123)` 初始化后迁移到 GPU
（设备打印 `cuda:0`），输入 batch / 生成 token 同步迁移。验证结果：

* 4.6 logits（`out[0][0][:3]` 等）与书**逐值一致**（权重一致 + TF32 禁用）
* 4.7 生成文本 `"Hello, I am Featureiman Byeswickattribute argue"` 与书**逐字一致**
* 参数量 163,009,536 / 124,412,160 不变

程序开头禁用 TF32（`setAllowTF32CuBLAS(false)`）保证 GPU matmul 精度与 CPU 一致。
