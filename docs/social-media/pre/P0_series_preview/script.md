## [0:00–0:15] 开场钩子

> 你看到的 LLM 教程，几乎全是 Python。
> 但你有没有想过：生产环境里的 LLM，是用什么语言跑的？
> 答案：C++。
> 这次，我想用 C++ 复刻一本经典教材——
> Sebastian Raschka 的《Build a Large Language Model (From Scratch)》。

## [0:15–0:45] 系列内容

> 整个系列一共有 **43 帖**，分四个部分：
>
> **第一部分，入门 7 章**。
> 从 Hello LibTorch 开始，到注意力机制、GPT 模型、预训练、分类微调、指令微调。
> 每章 3–5 帖，每帖 1–5 分钟口播。
>
> **第二部分，附录 3 篇**。
> 训练循环技巧、LoRA 参数高效微调、推理增强（CoT、Self-Consistency、PRM）。
>
> **第三部分，实战 3 个项目**。
> gpt-bash：自然语言转 Bash 命令。
> gpt-toolcall：让模型学会调工具。
> gpt-sft：通用 SFT 框架，CLI + HTTP 服务化。

## [0:45–1:15] 你能得到什么

> 跟着做，你能拿到三样东西：
>
> 第一，**跨语言数值一致**。
> 同一个随机种子，我用代码验证过，C++ 跟 PyTorch 输出完全一致。
> 这意味着你在网上看到的任何 Python 教程，都可以平移到 C++。
>
> 第二，**性能调优的真实数据**。
> 比如第 6 章分类微调，CPU 跑 16 分钟，GPU 跑 1 分钟。
> 这些数字不是 PPT，是我真机测的。
>
> 第三，**可部署形态**。
> 整个项目最终产物是一个 C++ 二进制 + 模型文件，
> 不需要装 Python、不需要装 PyTorch，扔到服务器就能跑。
